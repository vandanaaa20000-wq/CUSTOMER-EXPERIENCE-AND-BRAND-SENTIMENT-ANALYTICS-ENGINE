# CUSTOMER-EXPERIENCE-AND-BRAND-SENTIMENT-ANALYTICS-ENGINE

### Repository Overview & Description:
Short Bio / About SectionAn enterprise-grade Natural Language Processing (NLP) web application built with Python, Streamlit, and Scikit-Learn to automate multi-class brand sentiment analysis (Positive, Negative, and Neutral). Designed to convert unstructured customer feedback into actionable insights at scale.   Detailed README DescriptionThe Customer Experience & Brand Sentiment Analytics Engine is an interactive, end-to-end machine learning solution designed to help organizations automate feedback auditing, monitor brand perception, and mitigate customer churn triggers. 

### Key Technical Highlights:
Text Preprocessing Pipeline: Utilizes custom regular expressions (Regex) for efficient lowercase conversion, HTML/URL stripping, punctuation removal, and tokenization.   Feature Engineering: Implements TF-IDF feature extraction combined with L2 normalization to transform unstructured textual feedback into high-dimensional numerical representations.   Model Benchmarking: Evaluated and benchmarked 5 distinct machine learning models—including Multinomial Naive Bayes, Logistic Regression, and Random Forest—to maximize predictive accuracy.   Handling Data Imbalance: Deployed a Balanced Linear Support Vector Machine (Balanced Linear SVM) model, successfully capturing a peak 95.20% Accuracy while prioritizing minority class recall.   Interactive Deployment: Built an intuitive user interface via Streamlit supporting both single-text real-time evaluations and CSV batch uploads with downloadable template files. 

### Business Insights & Value Proposition:
Elimination of Manual Auditing Bottlenecks: Automates multi-class feedback analysis across thousands of customer touchpoints, drastically reducing manual review time and operational overhead for customer success teams.   Proactive Churn Mitigation: Equips cross-functional product and support teams with real-time sentiment data, enabling rapid identification and resolution of customer pain points before they lead to churn.   High-Precision Risk Detection: By utilizing a Balanced Linear SVM achieving 95.20% Accuracy, the system ensures high recall on minority classes (e.g., critical negative complaints), preventing severe customer dissatisfaction from going unnoticed.   Scalable Enterprise Workflows: Designed for flexibility by supporting both ad-hoc single-text analysis and bulk CSV batch processing with standardized templates, allowing seamless integration into existing organizational reporting structures.
